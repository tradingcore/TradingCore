📋 SECRETS NECESSÁRIOS NO GITHUB
---------------------------------

Acesse: https://github.com/tradingcore/TradingCore/settings/secrets/actions

Adicione os seguintes secrets:

1. OPENAI_API_KEY
   → Sua chave da API OpenAI
   → Obtém em: https://platform.openai.com/api-keys

2. EVENT_REGISTRY_API_KEY
   → Sua chave do Event Registry (busca de notícias)
   → Obtém em: https://eventregistry.org/

3. REMETENTE_EMAIL
   → Email Gmail que vai enviar os emails
   → Exemplo: tradingcore@gmail.com

4. REMETENTE_SENHA
   → Senha de App do Gmail (não é a senha normal!)
   → Como criar:
     1. Acesse: https://myaccount.google.com/security
     2. Ative Verificação em 2 etapas
     3. Vá em "Senhas de app"
     4. Crie uma senha para "Mail"
     5. Copie os 16 caracteres gerados

5. FIREBASE_SERVICE_ACCOUNT_JSON
   → JSON da Service Account do Firebase
   → Como obter:
     1. Acesse: https://console.firebase.google.com
     2. Selecione o projeto tradingcore-db
     3. Engrenagem → Configurações do projeto
     4. Aba "Contas de serviço"
     5. "Gerar nova chave privada"
     6. Cole o CONTEÚDO INTEIRO do arquivo JSON
